# SignalDojo Trademark Policy

> **Draft policy for legal review.** This policy is intended to distinguish official SignalDojo releases from third-party forks. It does not change or restrict the rights granted to the software under the GNU General Public License.

## 1. Purpose

The SignalDojo source code is free and open-source software. The GNU GPL permits anyone to run, study, copy, modify and redistribute the covered software under its terms. Copyright permissions do not automatically grant permission to use project names, logos or branding in a way that implies an official release, sponsorship or endorsement.

This policy governs use of the **SignalDojo** name, the SignalDojo logo, application icon and closely confusing variants (collectively, the **SignalDojo Marks**). No statement in this document claims that a mark is registered in any jurisdiction.

## 2. Uses that do not require separate permission

You may:

- Truthfully state that software is SignalDojo or is based on SignalDojo.
- Use the SignalDojo name when discussing, reviewing, teaching, documenting or linking to the project.
- Redistribute an unmodified official release while retaining its original notices and making clear where it came from.
- State compatibility in a factual manner, such as “compatible with SignalDojo projects,” provided the presentation does not imply endorsement.
- Use screenshots of the official application for commentary, documentation or tutorials, subject to applicable law.

## 3. Modified and unofficial distributions

Modified builds and forks remain redistributable under the GNU GPL, but they must be clearly distinguishable from official SignalDojo releases. Unless you have written permission from the project maintainer, a modified distribution should:

- Use a different product name, application icon and primary logo.
- State prominently that it is an unofficial modified version based on SignalDojo.
- Identify the changes and the party responsible for the modified build.
- Avoid naming its installer, executable, website, package or download in a way that could reasonably be mistaken for an official SignalDojo release.
- Avoid statements suggesting sponsorship, certification, approval or support by the SignalDojo project.

A descriptive statement such as **“ExampleLab Analyzer — based on SignalDojo”** is preferable to presenting a modified build simply as **“SignalDojo.”**

## 4. Official releases

An **official SignalDojo release** is a release published by the SignalDojo project maintainer through the project’s designated website or source-code release channel. The project may continue to provide tested official Windows installers while third parties exercise their GPL rights to build and redistribute the software independently.

The availability of an official installer does not prevent others from redistributing the software under the GPL. It only identifies which binaries the project itself has built and tested.

## 5. Uses requiring permission

Written permission should be obtained before using the SignalDojo Marks:

- As the primary name or branding of a modified product or service.
- In a company, organisation, domain, package repository or application-store name.
- On merchandise or in advertising that suggests an official commercial relationship.
- In a logo or icon derived from the SignalDojo logo for a third-party distribution.
- In any misleading, defamatory or unlawful manner.

## 6. No effect on GPL rights

This trademark policy does not prohibit copying, modifying, compiling or redistributing the SignalDojo source code. It does not add a software-licence restriction to the GPL. A distributor who does not have permission to use the SignalDojo Marks can comply by using different branding and accurately describing the software’s origin.

## 7. Questions and permissions

Requests concerning branding or permission should be sent through the contact channel published on the official SignalDojo project website or source repository.
